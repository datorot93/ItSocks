Daniel Toro (daaltoto@gmail.com) is the developer and owner of ItSocks, a socks e-commerce platform.

He works across all three layers of the stack:
- Backend: FastAPI + SQLAlchemy 1.3 + Pydantic v1 (Python 3.9)
- Frontend: React 18 + Vite + Redux legacy (not RTK)
- Admin panel: React Admin v5 + Vite + MUI

He is comfortable with full-stack development but the project has accumulated bugs (typos in field names, missing handlers, wrong imports) that are documented but not yet fixed.

He uses Claude Code to build test infrastructure from scratch, including setting up test runners (pytest, vitest), configuring coverage, and implementing comprehensive test suites.
